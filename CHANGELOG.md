# Changelog

All notable user-visible changes to the ESPHome TOS application package.

## 2026.10.2-1 — 2026-11-14

### Added
- First release. ESPHome (`esphome/esphome:2026.10.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8032 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/esphomedocker/`.
